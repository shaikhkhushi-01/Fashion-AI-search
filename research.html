Research & Engineering Dossier

From fashion search
to a measurable AI system.

Fashion AI Discovery is a research-oriented retrieval system built to study how semantic understanding, lexical relevance, explicit attributes, constraints and ranking signals interact in natural-language fashion search.

01 / Research question

Does combining retrieval signals improve fashion discovery?

The project tests whether a hybrid pipeline can retrieve and rank relevant fashion products more effectively than individual retrieval strategies. The important engineering principle is measurement: the system documents both improvements and cases where simpler baselines remain stronger.

Research hypothesis

Combining semantic similarity with lexical relevance, explicit attribute matching, budget constraints and ranking features should provide complementary retrieval signals for natural-language fashion queries.

02 / Architecture

A layered retrieval pipeline.

Query understanding extracts structured intent. Candidate generation then combines semantic and lexical evidence, applies hard constraints, fuses candidates and reranks them. Personalization and explanations are exposed as downstream signals rather than hidden magic.

03 / Evaluation

Results are benchmarked, not assumed.

The repository contains a deterministic benchmark artifact with 250 evaluation queries, a 200-query validation split and a 50-query held-out test split. Evaluation uses Precision@5, Recall@5, F1@5, MRR, NDCG@5 and MAP, alongside bootstrap confidence intervals.

Interpretation

On the current curated benchmark, hybrid retrieval improves NDCG@5 over semantic retrieval, but lexical and category baselines remain stronger on aggregate metrics. The project treats this as a research finding and limitation rather than claiming universal superiority.

04 / Ablation & statistics

What actually contributes?

Twenty-eight weight configurations were evaluated using a validation/test split. The repository also contains paired comparisons and 2,000 bootstrap iterations for confidence intervals.

ABLATION

Signal contribution

Semantic-only, semantic+attributes, lexical-only, lexical+attributes and full-hybrid configurations are compared to expose whether added complexity produces measurable gains.

GENERALIZATION

Held-out evaluation

Validation tuning is not promoted automatically. A tuned configuration is retained only when the held-out test evidence supports generalization.

05 / Robustness & error analysis

Failure is part of the artifact.

Robustness suite

  • Empty and whitespace queries
  • Case and spacing variations
  • Budget constraints
  • Very short and repeated-character queries
  • Special characters and unrelated queries

Error taxonomy

  • Complete miss
  • Late relevant result
  • Partial recall
  • Attribute mismatch
  • Baseline recovery/regression analysis

08 / Research Lab

From prototype to evidence.

The repository now includes two research-facing tools: a browser-based human relevance annotation studio and a real CLIP-based cross-modal retrieval prototype. These are deliberately separated from the production ranking claims so experimental evidence is not confused with completed validation.

Human relevance annotation

50 natural-language tasks with four-level relevance labels (irrelevant → exact match), browser-local annotation, JSON export and a protocol for independent annotators, agreement measurement and held-out evaluation.

Open annotation lab →

Real multimodal retrieval

CLIP inference is wired into a browser research page for text→image and image→image retrieval. The current catalogue uses deterministic local illustrations, so the page explicitly treats visual quality as a prototype until licensed real product imagery is connected.

Open multimodal lab →

Proposed research contribution

The project now defines an Attribute-Gated Multimodal Ranker (AGMR): a trainable ranking formulation combining lexical, semantic, explicit-attribute, budget, visual, style and occasion signals. It is an original project hypothesis/prototype, not presented as a validated novel published model until human-labelled experiments demonstrate an improvement.

07 / Limitations & next research

What should be investigated next?

  • The current catalogue and relevance benchmark are controlled research artifacts, not a representative production-scale fashion dataset.
  • The benchmark is not human-labelled at large scale; broader external evaluation is needed before making real-world generalization claims.
  • Visual previews are deterministic local fashion illustrations, not product-specific photographs or a trained image-generation model.
  • Future work: human relevance annotation, larger multi-brand catalogues, CLIP-style vision-language retrieval, cross-modal query experiments, learning-to-rank with real preference labels, and significance-tested online evaluation.

08 / Portfolio signal

Engineering + research discipline.

The goal of this project is not to make a UI that merely looks intelligent. It is to make the intelligence inspectable: define a question, implement competing methods, measure them, analyze failures, document limitations and keep the experiment reproducible.
